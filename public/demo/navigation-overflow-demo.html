PC 导航溢出折叠 · 交互演示

三个演示对应三个待决策点:① 主行无限级 hover 级联(父项可点击直达第一个叶子);② 溢出折叠 + 更多下拉「纯展开」;③ 溢出折叠 + 更多下拉「父项直达叶子 + 箭头展开」。演示数据含 4 级层级,验证无限级递归。点击任何链接会弹 toast 模拟跳转,不会真的跳走。

演示 1 · 主行无限级 hover 级联(trigger = hover,父项可点击)

hover 父项 → 展开子菜单(向右无限级联);点击父项 → 直达第一个可用叶子。试试沿「新闻中心 → 公司新闻 → 最新动态 → 2026 年度活动」hover 四级;靠右的「帮助支持」子菜单会自动向左弹(JS 实时边缘检测,不是写死的);拖动宽度滑块把「帮助支持」挤到右缘看效果。子菜单带 300ms 关闭延迟 + 与父行 5px 重叠,鼠标斜向穿越不会断链。

容器宽度1040px
对应你提的规则:子菜单 hover 弹出 ⇒ 父项可点击(点击直达第一个叶子)。此时父项是真实 <a href>,中键/右键新标签、SEO、复制链接都正常。hover 展开由 JS 管理(打开即时、关闭延迟 300ms),真实项目用 Alpine 实现同款逻辑。

演示 2 · 溢出折叠 + 更多下拉「纯展开」(trigger = click 的形态)

拖动滑块改变导航条宽度,看「更多」按钮如何动态占据最后一个能放下的位置;被折叠项中有激活态时「更多」会高亮(点击「网站地图」试试)。更多下拉里父项点击只负责展开分组,不可跳转,叶子才是链接 —— 与移动端手风琴交互一致。

容器宽度1168px
对应规则:子菜单 click 弹出 ⇒ 点击语义被「展开/收起」占用,父项纯展开。下拉内部是递归手风琴,任意层级。

演示 3 · 溢出折叠 + 更多下拉「父项直达叶子 + 箭头展开」(trigger = hover 的形态)

同样的折叠逻辑,区别在更多下拉里:父项文字本身是链接(直达第一个叶子),右侧箭头单独负责展开。hover 父项文字可见下划线反馈。适合「hover 模式下主行父项能点击,收进更多后依然能点击」的一致性诉求。

容器宽度1168px
箭头与文字分离点击目标,两者互不冲突;若你觉得箭头热区太小,也可以整行点击直达、长按/hover 出子级(不推荐,演示即可对比)。

演示 4 · 导航风格(style = primary / minimal)

同一条 hover 级联导航的两种皮肤。primary:主题色底 + 白字 + hover 为更浅主题色 + 选中为更深主题色;minimal:白底 + 主题色字 + 浅灰 hover + 选中为主题色浅底、文字加深(暗黑模式下自动翻转为深底 + 主题色浅亮字)。点按钮切换暗黑验证。「联系我们」为选中态示例。

对应配置 navigation.style:primary(默认,与现有站点一致)/ minimal(简约风,亮暗自适应)。两种风格共用同一套折叠、级联、边缘检测逻辑,只是 CSS 变量不同。

演示 5 · 手风琴专项(层级区分 + 移动端配色)

手风琴父子级的区分:子级文字缩进(缩进做在链接元素内部 padding 上,hover 背景通栏变色,同移动端现有方案)+ 父级字重 600 / 叶子字重 400。三个面板:两部手机模拟移动端菜单(primary / minimal 两种配色,含底部登录注册区),右侧为「更多」下拉实际宽度(248px)。默认展开「新闻中心」一支展示层级效果。点按钮切换暗黑验证 minimal。
