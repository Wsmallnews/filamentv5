① 规格选择：三种形态（对应参考截图）

形态参考样式适用
胶囊 蜜雪冰城 纯文字 pill，选中实底反白（= 现状 sn-badge / sn-badge-solid-primary） 无图规格的兜底形态；紧凑、扫读快
列表 淘宝（紧凑） 流式换行、宽度随内容（短选项一行摆多个）；小图 40px + 名称/价格；名称超过整行宽度才截断「…」（title 悬停全名），选中展开换行全显；选中 = 描边 + 浅底 有图规格的默认推荐（选项多少都放得下，PC 不空旷）
大图 淘宝形态② auto-fill 自适应网格：卡宽钳 ~120–160px，列数随容器（436px 容器 → 3 列、600 → 4 列、750 → 5 列，淘宝 PC 同款）；正方形图 + 名称/加价，选中描边 + 图上角标 颜值驱动品类（花束/礼盒/甜品），图即卖点

规则：规格组级配置形态，无图规格组恒为胶囊（与淘宝一致——尺码等无图维度不切形态）；同一产品内可混排（杯型用大图、温度用胶囊）。形态切换入口放在规格组标题右侧（淘宝同款位置），默认形态由后台规格组配置决定。

② 不可选置灰的联动（演示数据内置）

纪念杯仅「正常冰」可选 → 选了「少冰」后纪念杯置灰；「热饮 × 超大杯」「热饮 × 全糖」无组合 → 选热饮后超大杯/全糖置灰。算法与现有 product-buy.js 的 isSelectable 完全一致（变体矩阵反查），图片化不改变联动逻辑，只换选项的「皮」。

③ 附加项：按是否带数量分化（形态切换只作用于规格，附加项不参与）

  • 无数量组：与规格胶囊完全同款（选中实底反白，无加号无行卡片），蜜雪同款做法——用户无需区分「这是规格还是附加项」，交互心智一致；价格小字跟在名称后。
  • 有数量组：行式卡片 + 步进器（未选只见加号；点击后变「− 数量 +」，减到下限即取消，上下限到达时按钮置灰）；容器宽度自适应——容器 ≥400px 一行两个（PC 购买盒常态），更窄一行一个（窄手机），容器查询实现与断点无关。
  • 文字太多：胶囊/列表选项宽度随内容，名称超过整行宽度才截断（… + title 悬停全名），选中展开换行全显——不到整行不截断；行式卡片（固定列宽）名称 truncate 弹性收缩、价格/步进器固定不挤占。
  • 售罄：胶囊置灰不可点但仍可见（尾缀「已售罄」）；行式整行置灰 + 灰色「售罄」徽章。

④ 底部结算条：已选回显

左缩略图（= 组合推导图）+ 「已选：大杯 / 少冰 / 五分糖」+ 附加项摘要（珍珠×2 · 奶油顶×1）+ 合计价（变体价 + 附加项，× 数量）+ 低库存提示（≤3 件橙色提醒，来自变体 stock）。sticky 吸底，随时可见当前选择全貌——对应参考图中「已选 X 款」的回显区。

⑤ T10 落地映射（实现要点）

  • 规格值图：specSchema 契约里 specs[].children[].image 字段已就绪（现返回 null），T10 只需后台规格值表单加上传 + 前端消费。
  • 组合图自动推导：底部缩略图 = 首个带图规格组的当前选中值图片，全部选完命中变体后优先取变体级覆盖图（variant.image，后台可选填，不填自动推导）——商户零配置即可有组合图，特殊组合可精确覆盖。
  • 形态配置：产品级（或规格组级）加 selector_style: pill | list | grid，默认 pill 兼容现状；有图且未配置时建议 list（淘宝默认逻辑）。
  • 样式映射：胶囊 → 现有 sn-badge / sn-badge-solid-primary；列表/大图卡片 → 新增 sn-spec-option / sn-spec-option-selected 工具类（消费 --sn-radius-card / primary 令牌），不硬编码颜色。
  • 附加项改造：无数量组复用规格胶囊类（sn-badge / sn-badge-solid-primary）；有数量组行式卡片 + Alpine 步进器（逻辑复用现有 selectedExtras/extraNums），容器查询 @[400px] 两列。形态切换仅规格，附加项固定形态。

演示说明

· 形态切换（胶囊 / 列表 / 大图）仅作用于规格；附加项不参与切换：无数量 = 规格胶囊同款，有数量 = 行式步进器（容器 ≥400px 两列）。

· 列表形态为紧凑流式：选项宽度随内容，短选项一行多个；名称超过整行宽度才截断、选中展开全显——「纪念杯·情人节限定联名款」不到整行即全显，「周边联名保温杯…」超过整行演示截断。

· 可实际操作：选热饮看置灰联动、选超大杯 + 去冰触发「仅剩 2 件」、附加项点选看合计；数据结构与算法即 specSchema v1 + product-buy.js。
