素材管理 v3 · 逻辑目录 + hash 物理路径

核心变化：物理路径与逻辑目录分离——path = sn/{日期}/{内容hash}.{ext}（当天同内容秒传、隔天可重复、永不变化）； 目录是实体表（层级最多 3 级，可新建空目录 / 重命名 / 删除非空目录文件回落未归类）； 移动文件 = 改目录归属，path 不动，业务字段引用零影响。 试试：左树新建目录、拖/选文件后「移动到目录」、传同一张图两次（当天秒传提示）。
