# HasSnSubject::getSnSubjectHrefUrl 全面移除计划（精简版：无注册表，调用方直传）

## 背景与结论

- 契约方法 `getSnSubjectHrefUrl()` 由 7 个模型实现（cms 的 Post/Navigation/NavigationType、category 的 Category/CategoryType、comment 的 Comment、product 的 Product），**全部 `return null`**——从未真正产出过链接；且链接是消费方上下文属性（product 模块自身无前端路由，URL 由使用方决定），不应由模型持有。
- 方案：从契约**彻底删除**；panel 侧 `FilamentModelHelper::getUrl()` 回退 `resolveResourceUrl()`；前端侧由调用方在 Blade 组件上**直传 `href` prop**，未传时保持现有机制（渲染 div + 分发点击事件，调用方监听自行跳转）。
- 不建 HrefRegistry（本次反馈）；生态内全部实现返回 null，移除后**零行为变化**，对 userland 实现无 fatal（接口删方法合法）。

## 一、support 包

1. **契约** `src/Contracts/HasSnSubject.php`：删除 `getSnSubjectHrefUrl()`，仅保留 `getSnSubjectId/Title/Description/CoverUrl`。
2. **`src/Helpers/FilamentModelHelper.php`**：`getUrl()` 删除 `HasSnSubject` 分支（保留 `HasSnIdentifiable` 分支），模型链接直接走 `resolveResourceUrl($model)` 兜底（panel 语境链到后台资源页）。`getTitle/getCoverUrl/getDescription` 的 HasSnSubject 分支（固有展示数据）**不动**。
3. **文档**：`resources/boost/guidelines/core.blade.php` 更新 `HasSnSubject` 方法列表与 hasLink 机制说明（链接来源改为调用方直传 href / 事件跳转 / panel 走 resourceUrl）。

## 二、preference 包

4. **`resources/views/components/preferenceable.blade.php`**：props 增加 `'href' => null`（string|Closure|null），替换对 `getSnSubjectHrefUrl()` 的直接调用：
   ```blade
   $rawHrefUrl = $href instanceof Closure ? $href($preferenceable) : $href;
   $href = $rawHrefUrl ? (string) $rawHrefUrl : '';
   $tag = ($hasLink && $href !== '') ? 'a' : 'div';   // 其余渲染逻辑不变
   ```
   无链接时的 `wire:click.stop="$dispatch('sn-preference-preferenceable-click', ...)"` 事件分发**原样保留**。
5. **`resources/views/components/preference.blade.php`**：preferenceable 分支同上（支持 `href` prop）；preferencer 分支的 `$preferencer->getSnHrefUrl()`（HasSnIdentifiable）**保持不动**。
6. **文档**：preference 包 `resources/boost/guidelines/core.blade.php` 中 `getSnSubjectHrefUrl` / hasLink 相关说明同步更新。

## 三、各模型包（删除实现）

7. 删除 7 个模型中的 `getSnSubjectHrefUrl()` 方法及仅其使用的 `HtmlString` import：
   - cms：`Post.php:92`、`Navigation.php:83`、`NavigationType.php:53`
   - category：`Category.php:81`、`CategoryType.php:54`
   - comment：`Comment.php:72`
   - product：`Product.php:89`
8. 不做任何包级注册；调用方需要链接时：直接使用 Blade 组件传 `:href`、发布覆盖组件视图传 `:href`、或监听 `sn-preference-preferenceable-click` / `sn-preference-preference-click` 事件自行跳转。

## 四、app 层
