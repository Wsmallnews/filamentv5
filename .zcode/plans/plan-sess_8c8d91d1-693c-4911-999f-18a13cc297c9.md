# sn-* 设计系统令牌化 + 前端页面响应式改造方案（定稿：几何令牌 + 颜色字面量）

## 一、定稿决策

- **令牌化范围**：只令牌化需要「响应式 + 可定制」的**几何项**（圆角/阴影/ring/间距刻度）；**颜色保持现有 `@apply` 字面量写法**（dark: 成对保留），index.css 大部分长相不变
- **色变体不去重**：7 色 container/contour 保留显式写法（每块都是可读字面量）；以后想消除重复可随时升级为 Filament fi-color 式槽位变量，与本方案不冲突
- **写法仍是 @apply + Tailwind**：令牌消费用 v4 官方简写 `rounded-(--sn-radius-card)`，且仅出现在少数几何声明行；原生 CSS 仅限 tokens.css 的 media query 翻转、color-mix 动态色、滚动条三处
- **职责边界**：sn-* 类只管主题性、重复性、需统一改的样式；布局结构（flex/grid、列数、可见性）继续在 HTML 写 Tailwind 断点前缀
- **不做老写法兼容**：冲突处直接改调用方
- **架构与主流一致**：CSS 变量设计令牌 = shadcn/Radix Themes/Ant 的标准架构；响应式令牌（:root media query 翻转值）是唯一延伸，纯标准 CSS，删掉 media 块即退化为固定值

## 二、令牌清单（断点翻转点 lg = 64rem，"≥lg 一档、<lg 一档"）

| 几何令牌（响应式） | < lg | ≥ lg | 消费者 |
|---|---|---|---|
| `--sn-radius-card` | 0.375rem (md) | 0.5rem (lg) | sn-container/contour 全家、sn-rounded、sn-elevation 基元 |
| `--sn-space-page` / `--sn-space-page-y` | 1rem (gap-4/my-4) | 1.5rem | 新增 sn-page |
| `--sn-space-card` | 1rem (p-4) | 1.5rem (p-6) | 新增 sn-padded、sn-list-header/row |
| `--sn-shadow-card` / `--sn-shadow-card-hover` | 隐约单层 | shadow-sm 级 | sn-container/contour 的投影、sn-hover |

固定令牌：`--sn-radius-control`（按钮 0.375rem，控件圆角不做响应式）、`--sn-radius-pill`。
颜色令牌（仅 dark 翻转，仍以变量提供但数量少）：`--sn-ring-card`（gray-200/80 ↔ gray-800/60）、`--sn-ring-card-hover` ——用于统一"光环"，消除三套 ring 色并存。

写法示例（几何行用变量，颜色行保持现状字面量）：

```css
.sn-container {
    @apply bg-white dark:bg-gray-900 transition-all duration-300 ease-in-out;
    @apply rounded-(--sn-radius-card);
    @apply ring-1 ring-(--sn-ring-card) shadow-(--sn-shadow-card);

    &.sn-hover {
        @apply hover:ring-(--sn-ring-card-hover) hover:shadow-(--sn-shadow-card-hover);
    }
    /* sn-link / sn-active 颜色规则保持现状不动 */
}
```

效果：`sn-rounded` 一个类 = `rounded-md lg:rounded-lg`；sn-container 自带响应式圆角/阴影/ring；HTML 零断点前缀。

新增类：
- L2 基元（`@utility` 注册，可在 HTML 直接用、支持变体、可被 @apply）：`sn-elevation`（投影+光环）、`sn-ring-card`（纯光环）、`sn-radius-card`
- `sn-page`：页面骨架（container mx-auto flex flex-col grow + 响应式 gap/my），替代 25 处复制的 `container mx-auto flex flex-col grow gap-4 my-4`
- `sn-padded`：响应式卡片内边距
- `sn-list-header` / `sn-list-row`：列表头/行（分隔线 + 响应式 padding），去 preference 9 处复制粘贴

## 四、关键风险与实现注意

1. media query 不能用 CSS 变量：lg 断点硬编码在 tokens.css 的 2 个 media 块，改断点只改一处
2. `@utility` 定义在文件靠前位置供 `@apply` 解析；组合异常时回退为聚合类直接引用令牌（效果等价）
3. transition-all 在 resize 时会过渡圆角/阴影，效果轻微可接受；介意则改 `transition-[box-shadow,border-radius]`
4. 聚合类为 unlayered 规则、优先于 layered 工具类（现状即如此）；个别差异场景用 `!` 修饰或覆盖令牌
5. ring 颜色统一到 --sn-ring-card 后，cms footer 等处旧 ring 色需同步替换（阶段 3 处理）
